# ❄️ Snowfitter — Ski & Snowboard Gear Recommendation System

Live Demo: https://snowfitter.netlify.app/

---

## 🧠 Overview

Snowfitter is a recommendation system that helps skiers and snowboarders choose gear based on experience level, riding style, and physical fit.

The system is designed to structure an otherwise subjective gear selection process into a **data-driven ranking system based on compatibility scoring across multiple attributes**.

Working in the industry, I’ve seen how overwhelming gear selection can be for customers due to variables like boot fit, board width, flex profiles, terrain, and skill progression.

---

## ⚙️ How it works

Instead of simple filtering, Snowfitter:
- Maps rider inputs to structured product attributes  
- Applies weighted scoring across multiple compatibility factors  
- Ranks gear based on overall match quality  

Each recommendation is generated using a scoring-based system rather than static rules.

---

## 📥 Inputs
- Skill Level  
- Riding Style (Park / All-Mountain / Freeride)  
- Height / Weight  
- Boot Size  
- Terrain Preference  
- Riding Preferences
